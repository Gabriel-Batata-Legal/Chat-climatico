# 🌍 Clima IA

Um chatbot educativo sobre mudanças climáticas, sustentabilidade e meio ambiente.

## Funcionalidades

- Conversa interativa em português.
- Respostas sobre aquecimento global, desmatamento, poluição, energias renováveis, efeito estufa, reciclagem e água.
- Perguntas sugeridas para começar.
- Botão para limpar a conversa.
- Layout responsivo para computador e celular.

## Como executar localmente

Basta abrir o ficheiro `index.html` num navegador. Não é necessário instalar dependências.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub chamado `clima-ia`.
2. Envie os ficheiros `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma página.

## Tecnologias

- HTML

- JavaScript

## Nota

Este é um chatbot educativo baseado em respostas programadas. Não é um modelo de IA conectado à internet e não substitui fontes científicas atualizadas.
